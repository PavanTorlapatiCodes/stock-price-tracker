# 🚀 Stock Market Analytics Dashboard

A Full Stack **Stock Market Analytics Dashboard** built using **Python (Flask), JavaScript, HTML, CSS, and API integration**.  
The application fetches live stock data, stores it, performs analytics, and displays it in a modern cinematic dashboard UI.

---

## 📌 Features

• 📈 Fetch Live Stock Prices using API  
• 💾 Store Stock Data in CSV using Python  
• 📊 Analytics (Average, Max, Min, Latest Price)  
• ⚡ Real-time API integration  
• 🌌 Animated Particle Background (Canvas JS)  
• 🎨 Cinematic Modern UI  
• 🚨 Price Alert System

## ⚙️ Installation

Clone the repository

git clone https://github.com/pavantorlapati/stock-market-dashboard.git 

Navigate into the folder
cd stock-dashboard 

Install dependencies

pip install flask pandas numpy requests
Run the application
python app.py
Open browser
http://127.0.0.1:5000/
